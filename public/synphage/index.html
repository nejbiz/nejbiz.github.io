Gene map — sequence clusters (MMseqs2)

Showing all genes scroll to zoom · drag to pan

Cluster members

Hover a row to highlight that gene on the map. ⌘/Ctrl/Shift-click genes to compare several clusters.

Product sharing

Each row is one cluster representative (this view's clustering) of the selected function — one row per cluster; unclustered genes each get their own row. The row is labelled by the cluster's most common product. Each column is a phage; a filled cell = the cluster is present on that phage. A cluster on a single column is unique to one phage. Click a row to highlight that cluster on the gene map, list its members, and shade the phage columns it occupies (so you can see what else those phages carry); ⌘/Ctrl/Shift-click adds more. Hovering shows details (cluster, product, PHROG, length range).

Structure (ESMFold2)

Click a protein in the members table (top-right) to view its folded structure.

Genomic context (flanking genes)

Select a function in the gene-map legend. Each column is one instance of that function, centred on the focal gene (offset 0; upstream above, downstream below); flank cells are coloured by cluster identity — each distinct flanking cluster gets its own viridis hue (no repeats in the figure; grey = singleton). Moron / auxiliary-metabolic flanks are shown in shades of red (distinct morons = distinct reds; pale red = unclustered moron) so they stand out. Columns are grouped into one block per focal (cargo) cluster, and within a block ordered by flanking clusters — so you can see whether a cluster's members keep the same flanking genes (conserved flanks form horizontal colour bands) or sit in different contexts. The insertion-site table below ranks flank-pairs shared by different cargos (swap candidates). Hover a cell for details.
Insertion sites — flank-pairs ranked by how many distinct cargos sit between them; >1 cargo = swap hotspot. Click a row to highlight that site on the gene map, in this matrix (its columns), and in the table (click again to clear).

Cluster intersections (UpSet)

Bar height = sequence clusters shared by exactly that set of genomes, stacked by function. Click a column to filter the gene map.
